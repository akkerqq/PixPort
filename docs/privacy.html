Политика конфиденциальности

Актуальная дата: 13 октября 2026 г.

1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») регулирует порядок обработки информации пользователей программы PixPort и сайта PixPort (далее — «Сервис»), предоставляемого Администрацией PixPort.

1.2. Используя Сервис, Пользователь подтверждает согласие с условиями Политики. В случае несогласия Пользователь обязан прекратить использование Сервиса.

2. Какие данные мы обрабатываем

2.1. Программа работает локально и не собирает персональные данные. Передача фото и файлов идёт напрямую между телефоном и компьютером внутри локальной сети, на внешние серверы файлы не отправляются. На компьютере локально хранятся только настройки программы: выбранная папка, лицензионный ключ, параметры автозапуска.

2.2. Сайт является статическим (размещён на GitHub Pages), не использует cookies, счётчики и аналитику, не собирает данные посетителей.

2.3. Проверка обновлений: программа периодически запрашивает у GitHub сведения о новых релизах; при этом передаётся только номер текущей версии.

2.4. Оплата: платежи обрабатывает платёжный оператор. Данные банковских карт и счетов нам не передаются и нами не хранятся. Мы получаем от оператора только идентификатор заказа и статус оплаты — они нужны для выдачи лицензионного ключа Pro.

2.5. Поддержка: при обращении в поддержку (Telegram) мы видим предоставленные Пользователем данные переписки и используем их только для решения вопроса.

3. Цели обработки

Данные используются исключительно для: обеспечения работы Сервиса, выдачи лицензионных ключей после оплаты, связи с Пользователем по его обращениям.

4. Передача третьим лицам

Передача информации третьим лицам возможна только: платёжному оператору и банку — в объёме, необходимом для проведения платежа; в случаях, установленных законодательством.

5. Хранение и защита

Данные программы хранятся локально на устройстве Пользователя. Переписка поддержки хранится в мессенджере Telegram. Мы принимаем разумные меры для защиты получаемой информации, однако не гарантируем абсолютную безопасность передачи данных через интернет.

Передача файлов между телефоном и компьютером осуществляется по локальной сети; ответственность за доступность и безопасность самой локальной сети (роутер, настройки Wi-Fi, брандмауэр) несёт Пользователь.

6. Права пользователя

Пользователь вправе запросить удаление переписки с поддержкой, обратившись в поддержку. Настройки и данные программы удаляются вместе с удалением программы с компьютера.

7. Изменения Политики

Администрация вправе вносить изменения в Политику. Новая редакция публикуется на этой странице и вступает в силу с момента публикации.
